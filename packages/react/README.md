# @natsail/react

`@natsail/react` provides a NATSail provider, runtime status hooks, session selectors, Core subscription hooks, and serial reducer hooks.

```sh
pnpm add react @natsail/core @natsail/session @natsail/react
```

The provider owns neither the runtime nor the session registry. The application closes both objects.

See the [NATSail README](https://github.com/thedonmon/natsail#shared-session-adapters) for React examples.
